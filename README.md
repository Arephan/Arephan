# Han Kim

Full-stack engineer in Quebec. I like systems that are boring to operate: strict types, clear failure modes, and a plan you can read before anything changes.

Most of my work is TypeScript and Rust, from billing and signup systems at Atlassian to Kubernetes developer tools and AI-agent infrastructure.

## Things I've built

- **[setup-as-code](https://github.com/Arephan/setup-as-code)** (Rust). Terraform for a personal AI assistant. One manifest, `plan` before `apply`, and safety policies that fail the run.
- **[rings](https://github.com/Arephan/rings)** (Shell). A template for agents that run unattended on a loop and check that the work actually happened.
- **[sac](https://github.com/Arephan/sac)** (TypeScript). Save a Claude Code setup as a git repo and restore it on a new laptop.
- **[slack-claude](https://github.com/Arephan/slack-claude)** (JavaScript). Talk to the Claude Code on your own laptop from Slack, with no public URL.
- **[quebec-er-wait-times](https://github.com/Arephan/quebec-er-wait-times)** (Python). An hourly archive of occupancy at all 120 Quebec emergency rooms, from the province's open-data feed.
